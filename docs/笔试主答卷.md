## 产品定位与结论

投资问答的错误，往往不只表现为一句答案不准确，还涉及财务期间混用、证据缺失、风险随画像消失，以及修复后没有重新验证。本产品面向投资 Agent 的 AI 产品经理与质量运营，让负责人走完“发现问题—对照证据—修改规则—回归验证—记录结论”的治理链路。

已交付可操作的公网 MVP，模型调用由用户手动触发。当前聚焦 F02、F07A、F07B 三个构造用例、两个母题；不将小范围演示包装为生产级投研或全量金融质量治理。

## 先让用户完成一个具体任务

首页优先开始或继续排查。核对页未运行时只突出当前动作，完成后将结果放首位；回答证据与笔记按需展开。建立候选后直接进入版本回归，先看固定范围的结果和阻断，再查看配置差异与审计。

| 步骤 | 操作 | 完成标准 |
| --- | --- | --- |
| 核对回答 | 生成或核验已有构造回答，对照参考并记录问题 | 结果、来源与问题记录可追溯 |
| 编写修复方案 | 修改 Prompt，建立候选，保留范围与核验参考 | 候选已建立，效果仍待验证 |
| 验证修复效果 | 手动运行，查看原回答与候选结果 | 全部必检项有明确结果，异常保留未知 |
| 记录处理结论 | 范围通过、待补证、退回或归档，并导出 | 决定与修订绑定，刷新后可恢复 |

界面使用直观全称、线条导航和可收起侧栏。桌面在80%至150%缩放时保持同一模块排列；放大后宽度不足可滚动，不抵消用户缩放。

# 质量标准与个性化治理

## 按意图定义标准

| 意图 | 质量标准与可计算检查 | 当前程度 |
| --- | --- | --- |
| 财务指标 | 实体、指标、期间、口径、单位和引用对应；数值一致 | 当前可运行主链路 |
| 画像化解释 | 同一事实保持一致，必要风险不能因激进偏好消失 | F07A/F07B构造画像与历史证据 |
| 行情时效 | 价格类型、交易状态、报价时点、公式与过期提示 | 已定义标准，未接实时MCP |
| 热点事件 | 事实、传闻与观点分开，证据时点及更正关联 | 设计范围，未实现持续更正流 |

PASS表示本项在当前依据下通过；FAIL表示发现明确问题；UNKNOWN表示缺证据、接口异常或无法判断；NA仅用于明确不适用。未运行和接口成功均不能视为质量通过。

数值检查先对齐实体、指标、期间和单位，再允许精确原值或规则指定的正确 HALF_UP 舍入值。例如参考8.234，精确值8.234与两位舍入8.23可通过；8.231不能因为“接近”而放行。确定性规则只核验已抽取声明，不保证自动找出答案的全部事实错误。

## 自动评测与人工职责

| 机制 | 职责 | 不应承担 |
| --- | --- | --- |
| 模型裁判 | 抽取核心声明，辅助任务匹配、风险与表达检查 | 充当独立事实真值 |
| 数据与规则 | 对齐可定位参考，核验数值与口径 | 替代所有语义理解 |
| 人工复核 | 阅读引用、追加理由与有限范围判断 | 覆盖原始结果或把未知直接放行 |
| 行为反馈 | 规划为发现异常和排序的信号 | 把点击、点踩直接当金标 |

当前未采集生产用户行为。人工笔记、处置和质量结果分开保存；归档不等于问题解决。原始未知项不能直接人工改成通过。

## 哪些内容不能因KYC改变

可调整解释难度、详略、举例和风险呈现顺序；不能改变公司财务事实、计算口径、证据时点、数据缺失和不确定性。用户偏好激进，也不能省略必要风险或包装确定收益。

当前仅使用构造知识水平、风险偏好和持有期，不采集真实账户、资产与身份证信息。公网任务由会话Cookie隔离；移除界面上的会话标签不改变隔离。清除Cookie或更换浏览器后无账号恢复机制。产品不执行交易，也不提供个性化荐股。

# 版本比较与真实问题修复

## 本轮公网真实案例

构造问题询问 DEMO_A 第三季度单季扣非净利润同比。待查回答写45%，冻结参考给出单季8.2%、前三季度累计45%。两者是不同期间口径，必须分别处理。

本轮在实际公网、实际浏览器与真实供应商接口完成三次请求：原回答裁判一次，候选生成一次、候选裁判一次。原回答为FAIL，候选为PASS；当前F02完整必检范围无阻断，已保存限定范围通过结论，并验证刷新恢复与审计导出。

| 对象 | 可追溯标识 |
| --- | --- |
| 原回答批次 | batch-f163e3534c8c41ef |
| 修复候选批次 | batch-64049fd7d24044e6 |
| 证据 | 公网真实主链路验收_v1.0.0.json |
| 可阅读审计 | 证据/公网完整走查/真实候选审计导出.json |

这是“构造原回答与重新生成候选”的整体方案比较，原回答生成配置未知，不能认定为Prompt单变量因果实验。单例FAIL转PASS也不能推算总体修复率。

## 如何比较与归因

候选关联父批次，记录Prompt、模型路由、生成材料、冻结测试范围、核验参考与修订。修改生成材料不改变核验参考，避免“换答案就修好了”。默认字段对照突出变化，原始JSON保留为高级审计。

Bad Case定位顺序是：生成输入输出—裁判抽取与引用—确定性规则—人工理由。F02可定位为期间口径混用；缺少单季参考应先补证；裁判没有抽取到完整指标时保留未知。不能从错误输出推断模型内部思考原因。

## 衡量落地价值

| 指标 | 计算口径及使用条件 |
| --- | --- |
| 严重问题检出率 | 正确检出严重问题数/独立金标严重问题数 |
| 误报率 | 被误判FAIL的正确适用项/金标正确适用项，UNKNOWN单列 |
| 必检项完成率 | 确定PASS或FAIL项/冻结范围全部适用必检项 |
| 修复率与新增失败率 | 同范围同参考下，错误变通过/原错误项；通过变失败/原通过项 |
| 必要风险保留率 | 实际保留风险项/独立清单要求风险项 |
| 复核效率 | 定位与复核耗时的中位数、P90及改判比例 |

当前缺独立金标和对照用户研究，因此不报告检出率、效率提升或ROI。已能验证的价值是将错误、版本、证据和结论联结起来，减少仅凭修复意图批准的可能。

# 实现与验证证据

## 可运行架构

原生HTML/CSS/JavaScript前端，Python HTTP服务与SQLite持久化。Docker通过已有Nginx和隧道提供 /investment/ 公网子路径，静态资源和API均按子路径解析。

批次、回答、运行、评估、复核、决定与笔记独立建模。决定绑定完整范围与修订；追加结果或复核会使旧决定失去当前适用性。笔记不修改质量结果。写操作检查会话归属、幂等标识和修订冲突。

模型密钥只在服务端私有配置中读取，不进入前端、公开源码、导出或审查包。适配器只抽取assistant最终文本，不将reasoning当答案；缺失、超时、截断或结构错误保留UNKNOWN。网络失败有错误、耗时和收尾记录。

用户最新要求是不设调用次数上限：全局与会话cap为null，旧审计计数仍累计。保留手动触发、单个在途任务、重复提交保护、失败不自动重试及输入输出长度限制。无次数上限不等于供应商账户余额无限。

## 证据分层

| 验证层 | 本轮事实 | 实际边界 |
| --- | --- | --- |
| 后端44/44 | Python HTTP、SQLite、会话、异常、门禁及高历史计数 | 模型为测试替身 |
| 前端57/57 | Node VM渲染、草稿、任务导航与门禁 | 不是实际浏览器 |
| 浏览器22项 | 实际无头Edge操作本地服务，覆盖失败、未知、候选、决定及刷新 | 模型替身，非真实质量指标 |
| 品牌与缩放10项 | 实际Edge通过浏览器缩放接口测80/100/125/150%，另测窄屏 | 无头浏览器及设备模拟 |
| 公网真实主链路13项 | 新建、真实核验、候选、结论、下载、刷新、隔离 | 新增3请求，单个构造F02 |

历史28次真实请求属于既有v0.6实验，含12次生成和16次裁判，不是28个独立用例。历史本地6次接口探索存在失败、不完整及离线后处理，不能描述为全部成功。本轮公网计数从6增至9，与历史实验分开列示。

升级保留原29批次、10笔记和6运行，未变更schema；随后本轮走查另建原回答与候选并追加记录。所有结论以随附JSON及审计为证，不以截图数量替代测试覆盖。

## 视频怎么看

视频展示公网已保存的真实核验结果，连续执行首页、失败定位、证据、笔记、配置比较、候选结果、回归、决定、历史和边界说明。录制期间不再请求模型；不将查看已保存结果描述为现场重新生成。

视频使用独立浏览器连续录制网页视口，未录用户桌面或浏览器地址栏。配音为离线AI语音，字幕辅助理解。视频不是截图拼接或预置结果冒充本次真实执行。

## AI使用与人工验证

Codex参与题目拆解、方案、代码、测试与材料整理；Gemini参与多轮独立评审和前端建议。评审意见经过源码、脚本或实际界面验证后采纳；外部评审文本本身不作为测试结论。本版附新的Gemini审查包，尚不声称完成第三方复审。

模型生成与裁判承担辅助角色，数值规则和人工理由分别可追溯。当前auto路由不等于固定底层模型，不宣称跨模型排名或金融安全认证。
