# AI使用与验证记录

Codex参与选题分析、产品方案、交互、源码、测试、错误处理和交付整理；Gemini由用户手动转交审查包，提供独立意见。AI不作为事实真值或最终质量认证。

关键采纳与纠偏：

1. 把历史回答当前适用性与普通候选修复比较分开；意见不能解除阻断，人工决定绑定修订。
2. 数值核验允许原值或正确HALF_UP舍入值，处理负数、前导小数点及单位精度；通过边界测试及早期跨语言校验，不用浮点容差吞掉错误。
3. 接口实际拒绝关闭思考；保留400和截断，调整低强度及预算。不因文档示例而宣称账户已经支持。
4. 裁判外层单层JSON围栏仅作格式规范化，原UNKNOWN保留；再通过真实F02运行验证新处理链路。
5. Gemini所称“超时信息未落库”并不准确：耗时已有运行记录。实际修复是失败状态与评估提交窗口，并补缺评估时回显。旧版review按钮也已禁用，实际发现并修复的是旧批次假加载。
6. 新版33项后端测试与4项界面逻辑均为模型替身/Node VM；公网HTTPS验证单列。真实浏览器工具被设置关闭，未伪造点击或截图。
