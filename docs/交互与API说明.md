# v0.8.1 视觉层级与信息收纳

## 问题与结果

原页面将用途说明、规则边界、执行提示和实际内容混排。本版把默认界面收敛为“标题—状态—核心内容—下一步”，解释按需展开。

| 视图 | 默认可见 | 按需查看 |
| --- | --- | --- |
| 工作台 | 新建排查、四步流程、示例入口、任务列表 | 页面用途、示例来源、会话规则 |
| 用例排查 | 问题、状态、回答/参考、检查结果、笔记 | 证据来源、高级配置、原始轨迹、规则解释 |
| 版本回归 | 成对版本、逐案例差异、阻断、主处置动作 | 可比性细节、处置语义、原始事件 |
| 历史实验 | 调用数、结果选择、回答与离线核验 | 样本限制、原始生成/裁判返回 |

顶部“使用指南”集中介绍完整操作、演示模式、费用次数、状态与复核、证据范围、会话和产品边界。帮助支持鼠标悬停、键盘聚焦、点击固定；Escape/外部点击取消固定。

## 前后端对应

未改业务接口、冻结配置、SQLite schema、核验规则及调用预算。server.py 只更新 VERSION。笔记、候选、复核、处置、决定、导出均继续使用已有后端约束，UI 不伪造新结果。

## 验证与限制

40 项后端模型替身检查、21 项 Node VM 界面逻辑检查；具体公网、容器、数据保留检查见各自结果文件。浏览器被 Work 设置禁用，未代替用户完成视觉、hover 定位、键盘/触屏和视频实测。没有新增付费 API 调用。


v0.8.1 补充：本轮仅优化视觉层级和信息收纳，原业务能力沿用 v0.8；解释集中至问号帮助和顶部使用指南。真实浏览器与录屏仍待用户完成。
