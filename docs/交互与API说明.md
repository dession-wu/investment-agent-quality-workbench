## 本版接口与数据

没有新增业务API或数据表；server.py仅更新版本与新建任务的空选/重复校验文案。原生成、裁判、复核、范围阻断和会话隔离不变。

预置演示状态只存在浏览器变量，不调用API，不写SQLite，不允许正式通过、复核、导出或创建审计凭据。正式任务的未运行/UNKNOWN仍阻断通过。

笔记草稿只恢复当前服务端会话有权访问的任务/用例ID，不读其他会话草稿；本机保存不等于服务端保存。清除Cookie后可能失去任务归属，清除站点数据或换浏览器不能恢复草稿。7天是恢复有效期，过期项在读取时清理；不是后台定时删除承诺。只输入匿名测试文本。处置弹窗草稿仍仅在当前页面内存。
