# 问衡 · 在线版交付说明

名称“问衡”：问指投资问答，衡指有依据地衡量回答与修复效果。副标题“投资问答质量评估与改进”。此为作品命名，未进行商标检索或注册。

## 本轮改动

1. 网页标题、品牌与页脚统一名称；不再用 QA 或投资 Agent 作为品牌。
2. 隐藏应用发布版本，技术接口/源码/审计导出保留版本追溯；任务修订属于业务内容，不删除。
3. 主界面删除套餐/供应商技术标注，保留用户需要的在线状态、剩余额度、失败和证据来源。
4. 公网接入真实模型。新建默认生成并核验，明确点击运行才发包；独立预置示例仍注明来源。

## 成本、安全与未做事项

部署保留原有20个任务、8条笔记，未重置预算。私有配置只读挂载在服务端，镜像/前端/源码/审查包均不含凭据。

每个数据库全局最多6次请求，失败也计数，不自动重置或增加；每次一个用例，生成+裁判最多2次，重评1次；全局只执行一项，幂等防重复。不是供应商资金封顶。本轮验证用2次，验收时还剩4次，可能随实际使用变化。属于有限额度在线版，不是无限公共服务。
