为AI产品经理提供一次有依据的版本评审：查证错误、记录假设、建立候选、比较固定范围、保存限定决定。此作品是校招MVP，不是投资推荐或生产发布系统。

- 在线体验：https://podnotes.cloud/investment/
- 固定源码：https://github.com/dession-wu/investment-agent-quality-workbench/tree/v0.8.3

**公网无模型密钥，不会产生付费模型调用。可新建、查证、写案例笔记、派生候选、记录退回/待补证/归档并导出；尚未运行的任务保持未知，不会出现虚假的成功评估。**

## 一次完整的操作

1. 首次首页点“体验一次完整排查”，进入独立预置四步示例；它不创建正式任务、不实时调用模型。已有任务时主入口改为“继续上次排查”。
2. 若要实际保存治理记录，点“新建排查任务”选择现有F02/F07A/F07B，进入核对页。点击页首下一步，对照回答与参考，保存本用例问题记录并打开修复方案。
3. 修改回答规则（Prompt），建立待验证版本，进入验证页。页首明确“效果尚未验证”，字段对照显示修改内容及范围/依据不变。
4. 有密钥且有额度时，明确点击“运行核验”才提交一个用例；完整范围无阻断后才可记录通过。无资源时主入口带往独立预置结果，明确不是当前候选的核验，可返回原任务；正式候选仍未运行。
5. 按实际结果保存待补证、退回修复或归档，或导出本批次审计记录；处置不会改变检查结果，归档不等于问题解决。
6. “过往真实案例”独立只读查看v0.6历史12次生成/16次裁判及v0.6.1离线分析，不能当作本轮模型调用或当前候选效果。

本机笔记草稿7天内可恢复，提交后的笔记由SQLite保存。匿名会话仍依赖Cookie；清除站点数据或更换浏览器无法恢复本机草稿。公网实例无模型密钥，真实新核验不可用。

## 本版：从任务开始，按下一步推进

- 首次首页突出“体验一次完整排查”；已有任务突出“继续上次排查”。真实历史为次要入口，新建任务仍仅提供现有预置用例。
- 用例页/验证页顶部直接显示当前任务或结论、下一步主按钮与完成标准；不用先读指南。
- 四步导航可点击，进度来自真实问题记录、候选、评估、决定/处置，不会点击就变成已核验。
- 保存问题记录后进入方案表单；建立候选后明确效果尚未验证。有资源时由用户显式运行，无资源时另看预置示例。
- 从候选查看预置时，明确“这不是你刚修改候选的核验结果”，提供返回原任务按钮，正式状态不变。
- 全范围通过才可记录通过；归档只属于处理状态，不表示问题解决。原始JSON保留为高级查看。

后端仅版本号更新，已有API/schema/预算/规则不变。此前草稿保护、字段差异和中文校验继续保留。详见本版变更说明与验收步骤。

## 已有前后端能力

四个视图分别承担会话任务概览、案例查证、完整范围版本决定和历史走读。导航hash保存任务/案例/视图，刷新恢复依赖同一Cookie；清除Cookie仍无法找回匿名会话。

v0.8 已实现并在本版保留：

- `cases[].workflow_status`：UNRUN / RUNNING / EXECUTION_ERROR / NEEDS_EVIDENCE / FAIL / PASS，区分业务原因，不改变原检查PASS/FAIL/UNKNOWN/NA语义。
- `POST /api/batches/{id}/notes`可带可选`case_id`，校验属于冻结范围；旧笔记保持批次级。保存不改修订、不解阻断。
- `POST /api/batches/{id}/dispositions`：`revision, outcome, reason`；outcome只允许return_for_fix/needs_evidence/archive。只追加处置；执行中禁止，有有效通过决定时仅允许归档。处置与质量判定分开。
- `GET /api/batches/{id}/export`：导出当前会话本批次快照与来源；不含Cookie、私有配置或数据库文件。

保留执行、明确重试、已有回答重评、人工复核和通过决定接口。前后端均检查旧配置、执行中及预算。原始UNKNOWN/NA不能通过人工状态转换绕成PASS。

取消45%/8.2%字面值硬编码高亮。只有当前已完成评估的可定位声明才中性突出；没有评估不写“已修复”。轨迹按实际生成、裁判、规则、人工记录展示，缺节点明确未知/未执行，构造答案不编造原始生成上下文或模型推理原因。

## 数据、AI、画像与边界

当前范围为财务2母题3变体；DEMO_A、指标参考和KYC均为构造资料，未独立专家金标。事实、问答时点、口径、证据未知与必要风险不随画像改变；解释详略可以改变。F07A/B用于风险保留对照，不证明全面个性化有效性。

生成模型回答，裁判辅助语义、风险与核心数值声明抽取；Decimal核验可定位声明的口径、单位和原值/正确HALF_UP舍入。它不是独立全答案事实抽取器。人工追加复核和有限范围决定，原结果保留。

没有扶摇/iFinD权限、实时金融MCP、生产行为反馈、独立精度金标、登录多人审批或真实上线放行。行情/热点/更正的规则在前期方案中设计，未全量迁移。用户点踩不能直接作为事实真值。

SQLite追加记录不是不可篡改可信存证。处置“归档”不删除或锁死数据；后续评估变化会使绑定旧修订的决定/处置失去当前适用性。导出本批次不等于自动导出成对批次，如需双方原始记录分别导出。

## 本地运行与成本

Python 3.12标准库、SQLite、原生前端，无pip/npm运行依赖。

```bash
python server.py --port 8765
docker compose up --build -d
```

Docker默认本机8766；公网是独立无密钥实例，沿用既有持久卷。可配置服务端环境变量`QWEN_TOKEN_PLAN_API_KEY`，`.env.example`留空，不自动读取。Token Plan Responses请求模型auto，实际固定型号未披露。

有密钥实例每个数据库最多6次调用，失败也计数，跨Cookie/重启保留；每次一个变体，新生成最多2次、重评1次。生成输出768、裁判1536 tokens，输入超8000字符拒绝，不自动重试或换供应商。这不是账户资金封顶。原开发数据库已6/6，本版新增付费调用0次。
