# 问衡

投资问答质量评估与改进。让 AI 产品经理对照证据、建立修复候选、核验固定范围并保存有依据的结论。

在线地址：https://podnotes.cloud/investment/

本版已授权接入公网模型调用；新建任务默认生成并核验，必须点击运行才发包。当前仍限定 F02/F07A/F07B 三个财务构造用例，不支持任意用户金融材料导入，不是实时投研工具。

## 体验

首页“开始质量排查”→选择用例，创建任务→“生成回答并核验”→对照原始回答、参考与结果→保存问题，建立修复候选→运行候选→完整范围必检项通过后才可记录结论。已有任务继续上次排查。操作示例保持独立教学来源，不写正式结果。

## 成本与安全

保留每个数据库全局最多6次请求，失败计数，跨会话与重启保留；不自动增加、不重置历史预算。每次一个用例，生成+裁判最多2次，重评1次；会话同样受上限约束，调度前检查完整链路所需额度。全局仅运行一项，重复提交幂等。不自动重试或切供应商。额度不是账户资金封顶；在线只属于有限额度开放使用。

密钥由服务端只读挂载私有配置，镜像、前端、源码、导出与审查包均不得包含。匿名 Cookie 隔离任务；清 Cookie 无账户恢复。当前未实现企业登录、多人审批、实时MCP、全意图金标或生产自动发布。

## AI 与数据

模型生成回答、辅助语义评估和声明抽取；Decimal 对已抽取的数值和口径核验，人工追加复核和限定决定。事实、必要风险和未知不因画像改变。数据与画像为构造资料，历史归档保留28次既有请求，不代表28个独立样本。笔记、退回、待补证与归档不改质量结果；SQLite不是不可篡改存证。

## 本地运行

Python3.12 执行 `python server.py --port 8765` 或 `docker compose up --build -d`。默认不带密钥。配置 QWEN_TOKEN_PLAN_API_KEY 或 INVESTMENT_CONFIG 指向服务端私有JSON即可启用；绝不提交私有配置。技术供应商仍使用既有 Token Plan Responses/auto 路由，不把底层型号描述为固定。

验证：`python test_mvp.py`、`node --check public/app.js`、`node test_ui.cjs`。真实浏览器验收与真实付费调用分别记录，不用VM代替浏览器。不承诺长期服务SLA，主机与网络必须保持运行。
