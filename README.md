# 投资 Agent 回答质量与个性化治理工作台

面向投资问答产品经理、测试及研究复核人员的校招作品。核心任务是用冻结的测试范围与证据，定位回答问题、验证候选修复，并保存可追溯的评审决定。

- Web演示：https://podnotes.cloud/investment/
- 源码：https://github.com/dession-wu/investment-agent-quality-workbench
- 当前应用：v0.7.3。公网实例不配置模型密钥，不会产生付费模型调用。

## 三分钟体验

1. 在“工作台”新建F02构造回答批次，进入“版本评审”。这里冻结的问题是单季扣非净利润同比，构造回答误用了累计45%，参考单季值是8.2%。未执行项保持UNKNOWN，不预填为已核验FAIL。
2. 查看问题、匿名画像、生成与评估参考、修订及基准摘要。保存处理意见，刷新后确认服务端恢复。保存意见不改变检查、解除阻断或成为评审决定。
3. 建立关联候选，选择P2模板或不同生成证据；查看候选仍继承完整范围和固定评测基准，未执行项不继承基线PASS。
4. 打开“历史实验”，查看既有28次真实调用的分组结果、回答、数值复核、原始请求与返回。原始记录为v0.6，离线分析为v0.6.1；查看不产生新调用。

公网演示支持上述操作，但不支持真实生成、裁判和重评：部署未提供密钥，按钮会明确禁用。在线可操作性和新模型调用是两件事。真实生成闭环曾在本机v0.7.1完成，证据位于“既有证据”，不冒充公网实例的新运行。

## 核心设计

平台分开保存案例、回答、运行、评估、人工复核、处理意见和决定。修改候选保留基线；判断变化会使旧决定失效，原决定不覆盖。当前范围内有FAIL、关键UNKNOWN或未执行项时，不能保存通过决定。

生成证据与核验参考分列，避免修改输入时悄悄改写真值。冻结配置包括问题范围、模型/Prompt、生成数据、评估参考、裁判参数、数值规则和后处理版本。支持Prompt及生成数据候选；当前默认接口只有auto，不能据此宣称实现固定底层模型的独立对照实验。

## AI与规则的分工

- 生成模型回答问题；裁判模型辅助任务、表达安全、风险遗漏及核心数值声明抽取。
- Python Decimal负责可定位核心声明的口径/单位/数值核验，允许原值或正确HALF_UP舍入值，不用相对容差放过错误。
- 人工处理争议并追加复核；UNKNOWN不能靠意见或转一圈状态变成通过。该项目没有独立专家金标团队，不能把候选人的复核称为第三方认证。
- 处理失败时保存UNKNOWN；实际响应先进入processing，最终失败状态与评估同事务提交。重启中断不自动重试，即使无对应评估也能回显已有失败证据。

## 个性化、热点与隐私

客观事实、问答时点、指标口径、证据缺失状态与必要风险不能因KYC画像改变；术语、详略和解释方式可以适配。构造F07A/B仅改变风险承受能力，必要的应收逾期18%及回款/减值风险不应对激进用户省略。当前三变体不构成全面个性化效果证明。

热点的来源、更正和当时可获得性在设计材料与旧原型中定义；H05当前适用性复评尚未迁移到本服务端。不得把新证据下的旧回答适用性变化计算成模型修复率。

只用构造公司、匿名KYC及既有公开披露快照，不上传真实个人身份或持仓。没有扶摇/iFinD权限，未接入金融MCP或实时行情。Cookie会话隔离不是登录和多人审批体系；清除Cookie不能找回旧会话。公开演示请只输入匿名测试文本。

## 运行

Python 3.12标准库、SQLite、原生HTML/CSS/JS，无pip或npm运行依赖。

```bash
python server.py --port 8765
```

访问http://127.0.0.1:8765/。若配置服务端环境变量QWEN_TOKEN_PLAN_API_KEY，可启用百炼Token Plan Responses接口，模型请求auto；实际固定型号未披露。不要把Key写进前端或提交仓库。`.env.example`仅为留空示例，不自动读取。

```bash
docker compose up --build -d
```

默认容器本机端口8766，SQLite在持久卷。公网演示使用独立无密钥实例，与开发数据库隔离。前端同时支持站点根路径和`/investment/`子路径反向代理。

## 成本约束

有密钥实例每个数据库全局最多6次请求，失败也计数，跨Cookie和重启保留。单次执行一个变体，生成+裁判最多2次、重评1次。输入超过8000字符拒绝，输出生成768/裁判1536 tokens；不自动重试或切换供应商。

供应商要求开启思考，采用低强度；不能保证10–15秒内返回。次数限制不是人民币费用上限，不同数据库不共享供应商账户预算。公网部署没有模型密钥，即使数据库为空也不能发送供应商请求。本机开发数据库此前已用6/6次，本版不新增付费调用。

开发中由Codex辅助方案、代码和验证，并多次通过用户转交Gemini获取第三方意见；AI建议经源码及实测核对后采纳，存在纠偏。每个新版本准备审查包，备包不等于已经审查。本版浏览器真实点击、窄屏布局和录屏尚未验收。

## 未完成事项

当前实际范围为财务问题2个母题3个变体；行情、热点、反馈接入回归集及24母题的完整方案没有全部落地。没有独立人工金标精度测量、自动生产调度、登录权限、多人审批或生产发布能力。用户行为反馈不能直接作为事实真值；反馈调查→补证→人工确认→加入回归集是后续路线。

后续优先：浏览器任务走查；独立标注集与F07配对风险验收；再接真实数据、补齐多意图和用户反馈闭环。业务指标目标为严重错误漏检、误拦、复核耗时及未知覆盖率，尚无线上收益或效率提升数据。
