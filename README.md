# 问衡

投资问答质量评估与改进：对照证据、修复回答规则、验证固定范围、记录处理结论。

在线体验：https://podnotes.cloud/investment/

## 使用

新建排查任务 → 核对回答 → 记录问题并建立修复候选 → 验证修复效果 → 保存本范围结论。四个模块使用线条图标导航，可收起、展开，偏好保存在当前浏览器。核验由用户手动触发，完成后优先展示结果。

## 本版

全新对话核验SVG标志，名称和副标题分两行；移除额度与匿名会话标签。根据最新要求，全局与会话均不设调用次数上限，旧审计计数保留且持续累计。接口cap为null。保留单个在途任务、幂等和失败不自动重试。模型密钥仅在服务端读取。

后端44项、前端VM57项、实际无头Edge工作流22项和品牌导航17项检查通过；浏览器模型部分使用替身，本轮新增付费调用0。公网验证见随附JSON，不将模拟结果算作真实金融质量证据。

## 本地启动

Python 3.12运行 `python server.py`，默认本地端口8765。无密钥仍可记录、比较与查看历史；真实核验需使用服务端私有配置路径INVESTMENT_CONFIG，参考server.py及.env.example，不把凭据放入public或源码。Docker使用Dockerfile与compose.yaml。

测试：`python test_mvp.py`、`node test_ui.cjs`；浏览器脚本需要Playwright与Edge。

## 范围

当前仅F02/F07A/F07B三个财务构造用例，不是实时投研与任意导入平台。历史28条调用保留来源。任务以浏览器Cookie隔离，清除后无法恢复；没有企业账号和多人协作。视频仍需单独完成真实连续录屏。详细变更和验证边界见docs/问衡在线版交付说明.md。
